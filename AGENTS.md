# Storava Web Agent Guide

- با کاربر فارسی صحبت کن.
- Keep code and identifiers in English.
- Read every file before editing it.
- Perform web development only on `feature/storava-web`.
- Do not break the WPF or desktop projects.
- Do not introduce web-specific code into Windows layers.
- Never upload user files.
- Build a modern, bespoke, production-quality interface.
- Generic or template-like UI is not accepted.
- The scanner must operate on real user-selected files.
- Mock data is not accepted as a finished feature.
- Scanning and importing must not block the main thread.
- Build and test after each phase.
- Do not commit, push, merge, or rebase without user permission.
- Do not begin the next phase without explicit user approval.
